# Aventuras programadas · Juego primer ciclo

Juego web de Pensamiento Computacional e Inteligencia Artificial para primer ciclo.

## Cómo publicarlo en GitHub Pages

1. Creá un repositorio nuevo en GitHub (por ejemplo `aventuras-programadas`).
2. Subí **todo el contenido de esta carpeta** a la raíz del repositorio, respetando las carpetas
   (`index.html` tiene que quedar en la raíz, junto a `portada/`, `mapa/`, `misiones/` y `docentes/`).
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   elegí la rama `main` y la carpeta `/ (root)`, y guardá.
4. A los pocos minutos el juego queda en `https://TU-USUARIO.github.io/aventuras-programadas/`.

Si subís los archivos desde la web de GitHub (“Add file → Upload files”), arrastrá las carpetas
completas. GitHub acepta archivos de hasta 25 MB por esa vía; el más grande del juego pesa 13 MB.
